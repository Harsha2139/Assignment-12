1. Project Overview

This project is a complete browser-based practical programs website created for the HTML, CSS and JavaScript laboratory assignment.

The project provides a central dashboard and separate program pages so that every practical experiment can be opened independently in a web browser. The design uses a custom blue + green colour theme, responsive layouts, consistent cards, clear navigation, and interactive demonstrations.

The experiment titles and organization are based on the supplied Experiements (1).pdf assignment list.

12. How to Run the Project

No installation or build process is required for the basic HTML, CSS and JavaScript practical pages.

Steps

Extract the project ZIP file.

Open the project folder.

Open index.html in a modern web browser.

Select HTML Programs, CSS Programs or JavaScript Programs.

Open any experiment from the section list.

Use the navigation buttons to move between experiments.

The project is intended to work as a local browser-based practical website.

13. Browser and Internet Requirements

Most experiments run locally in the browser without a server.

Some experiments depend on browser capabilities or external services:

Weather application requires an internet connection and the required API access.

Currency converter requires an internet connection and the required API access.

Fetch API demonstrations may require internet access depending on the endpoint used.

Geolocation requires browser permission and an environment that supports the Geolocation API.

Online/offline demonstrations depend on the browser's network state.

Some browser features such as History and Location naturally affect or inspect the current browser page.

These requirements are browser-dependent and are not equivalent to broken local project links.
